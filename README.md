# Conectta | Rede social
Projeto desenvolvido para praticar PHP, MySQL, CSS e JavaScript, criando uma aplicação web inspirada em redes sociais.

## Funcionalidades (até o momento)

- Cadastro e login de usuários  
- Edição das informações do próprio perfil  
    * Nome  
    * Nome de usuário  
    * Biografia  
    * Foto de perfil
    * Imagem de capa
- Sugestão de usuários para seguir (atualmente limitada a 2 usuários)  
- Seguir e deixar de seguir outros usuários  
- Publicar, editar e excluir as próprias postagens  
- Favoritar e desfavoritar postagens de outros usuários
- Comentar nas postagens
## Tecnologias utilizadas

- HTML
- CSS
- PHP
- JavaScript
- MySQL
